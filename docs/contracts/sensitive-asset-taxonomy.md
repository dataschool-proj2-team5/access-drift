# Sensitive Asset Taxonomy

**버전:** v0.1  
**기준:** 2026년 6월 29일  
**상태:** Sprint 1 데이터 계약 참고 기준

이 문서는 Access Drift의 합성 데이터 생성, 자산 민감도 분류, Gold severity 매핑 검토에 사용할 민감 자산 예시를 정리한다.

PRD는 Critical/High/Medium의 제품 판단 기준을 정의하고, 이 문서는 그 기준을 데이터 계약과 샘플 데이터 설계에 적용하기 위한 상세 예시를 제공한다.

---

## 1. 민감도 기준

- **Critical:** 개인정보보호법, 신용정보법, 전자상거래법 등에 의해 법적으로 보호 의무가 강제되는 정보
- **High:** 유출 시 비즈니스 운영상 타격이 있는 핵심 자산
- **Medium:** 사내 업무상 공유가 필요한 내부 자산

High 자산이라도 고객 개인정보나 결제정보 접근으로 이어지는 경우 Critical로 승격한다.

## 3. 사용 기준

- 합성 데이터 생성 시 민감 자산 후보와 샘플 필드 구성에 사용한다.
- Gold severity 또는 Risk Card 표시 문구를 설계할 때 자산 민감도 근거로 참고한다.
- 실제 secret value, token value, private key value는 이 문서의 예시 항목에 있더라도 어떤 레이어에도 저장하지 않는다.
- 구체 컬럼명과 테이블 스키마는 각 레이어별 schema contract에서 별도로 관리한다.
